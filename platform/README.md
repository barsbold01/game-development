# Just in Time — Godot 4 прототип

Платформ тоглоомын дүрмийг эвдсэн санаа: **тоглогч дүрээ удирддаггүй.**
Гүйгч өөрөө баруун тийш гүйнэ, та хулганаар банз, трамплиныг чирж нүхний дээр
тавьж түүнийг аварна. Нүх явах тусам уртасч, хурд нэмэгдэнэ.

## Саад ба зоос
| Саад | Хэзээнээс | Яаж давах |
|---|---|---|
| Нүх | эхнээс | Банз (нүхэнд ойртуулахад магнитлана) эсвэл трамплин |
| Өндөрлөг | 500px | Хананы урд трамплин тавина |
| Өргөс | 1000px | Трамплинаар дээгүүр нь үсэргэнэ |
| Цох | 1600px | Трамплинаар үсэрч дээрээс нь гишгэнэ (+40) |

**Зоос → хамгаалалт:** раунд дотор 5–10 зоос (хүндрэл өсөх тусам олон) цуглуулбал
нэг удаагийн хамгаалалт автоматаар авна. Дараагийн үхэлд амь хасагдахгүй.
Хамгаалалттай байхад дахин дүүргэвэл +100 оноо.

**PERFECT:** хэсгийг тавьснаас хойш 0.45 секундэд гүйгч хүрвэл "PERFECT!" гарч
нэмэлт оноо өгнө. Дараалан хийвэл +25 → +50 → +75 → +100 болж өснө. Хоцорч тавих эсвэл
үхэхэд цуваа тасарна. Банз нүхийг хучсан, трамплин саадын өмнө байж л тоологдоно.

## Нээх
1. Godot 4.7 нээгээд **Import** → энэ хавтасны `project.godot` файлыг сонго.
2. **F5** (Run Project) дар.

## Удирдлага
- Хулгана / хуруу: хэсгийг чирж тавих
- Дарах эсвэл Space: эхлүүлэх, дахин тоглох

## Файлын бүтэц
| Файл | Юу хийдэг |
|---|---|
| `scripts/game.gd` | Autoload: оноо, амь, хурд, төлөв (MENU/PLAY/OVER) |
| `scripts/player.gd` | Гүйгч: өөрөө гүйнэ, унавал `died` сигнал |
| `scripts/draggable.gd` | Чирж болдог хэсгийн ерөнхий логик (тавиур, чирэх, буцаах) |
| `scripts/spring.gd` | Трамплин: draggable-г өвлөж, гүйгчийг шиднэ |
| `scripts/world.gd` | Газар/нүх/өндөрлөг, саад, зоосыг автоматаар үүсгэнэ, урамшуулал, дахин төрөх цэг |
| `scripts/coin.gd` | Зоос |
| `scripts/spikes.gd` | Өргөс |
| `scripts/enemy.gd` | Цох (дайсан) |
| `scripts/main.gd` | Камер, эхлэх/дахин тоглох, үхлийг зохицуулна |
| `scripts/hud.gd` | Оноо, амь, самбарууд |
| `scripts/sfx.gd` | Дууг кодоор үүсгэнэ (файлгүй) |
| `scenes/*.tscn` | Сценүүд: main, player, plank, spring |
| `sprites/*.png` | Пиксел арт (16px tile) |

## Цааш хөгжүүлэх санаа (прототипт ороогүй)
- Хана, хаалт, хөдөлдөг платформ зэрэг шинэ хэсгүүд (`draggable.gd`-г өвлөөд л нэмнэ)
- Гараар зохиосон түвшин (одоо санамсаргүй үүсдэг)
- Гүйгчийн нүүрний илэрхийлэл, "аврагдлаа!" эффект
- Хөгжим, дэлгэц чичрэх
