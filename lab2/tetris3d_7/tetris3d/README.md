# 3D Tetris — Godot 4

## Хэрхэн ажиллуулах

1. Godot 4.3 (эсвэл түүнээс дээш) татаж авна.
2. Godot нээж → **Import** → энэ хавтас доторх `project.godot` файлыг сонгоно.
3. **F5** дарна.

## Удирдлага

| Товч | Үйлдэл |
|---|---|
| `←` `→` `↑` `↓` эсвэл `WASD` | Хэвтээ хөдөлгөх (дарж барихад давтан хөдөлнө) |
| `Z` | Урагш хөмрөх (X тэнхлэг) |
| `X` | Хэвтээ эргэх (Y тэнхлэг) |
| `C` | Хажуу тийш хөмрөх (Z тэнхлэг) |
| `Shift` | Хурдан унагах (дарж барина) |
| `Space` | Шидэх (hard drop) |
| `Q` | Дүрс хадгалах / хадгалсантай солих (нэг дүрсэнд нэг удаа) |
| `+` / `−` эсвэл хулганы дугуй | Томруулах / жижигрүүлэх |
| `0` | Томруулалтыг анхны байдалд нь сэргээх |
| `P` | Түр зогсоох |
| `Enter` | Эхлэх / дахин эхлэх (тоглоом дууссаны дараа) |
| `H` | Удирдлагын жагсаалтыг харуулах / нуух |

## Тоглоход туслах зүйлс

Камер 45°-д тогтсон тул гүн ба чиглэлийг уншихад туслах хэд хэдэн зүйл бий:

- **Шалан дээрх W / A / S / D үсэг** — товч бүр дэлгэц дээр аль тийш
  хөдөлгөхийг шууд харуулна.
- **Дээрээс харсан газрын зураг** (баруун дээд буланд) — камертай ижил 45°
  эргэсэн. Нүд бүрт баганын өндөр бичигдэнэ, одоогийн дүрс цагаан хүрээтэй.
  Гүн таах шаардлагагүйгээр аль нүх хоосон байгааг харуулна.
- **Арын хоёр хананд тусах проекц** — дүрс аль эгнээ, аль өндөрт байгааг
  хананы тороос уншина.
- **Давхаргын өнгө** — буусан шоо өндрөөрөө будагдана: доор хөх → ногоон →
  шар → дээр улаан. Улаан харагдвал аюултай.
- **Lock delay** — дүрс газардсаны дараа `LOCK_DELAY` (0.5 сек) хугацаанд
  хөдөлгөж / эргүүлж болно. Хөдөлгөх бүрт хугацаа сэргэнэ (`LOCK_RESETS` удаа хүртэл).
- **Дараагийн + хадгалсан дүрс** — баруун дээд самбарт.
- **7-bag** — бүх дүрс нэг удаа гарсны дараа л дахин холино.
- **Эхлэлийн дэлгэц** — `Enter` дарах хүртэл тоглоом эхлэхгүй.

## Цэвэрлэгээний дүрэм

Нэг **мөр** дүүрэхэд арилна — бүтэн давхарга хүлээх шаардлагагүй.

Мөр гэдэг нь нэг тогтсон өндөрт байгаа шулуун эгнээ. 3D-д ийм эгнээ хоёр
чиглэлд байна:

- **X-мөр** — `y`, `z` тогтмол, `x = 0..W-1` → `W` ширхэг нүд
- **Z-мөр** — `y`, `x` тогтмол, `z = 0..D-1` → `D` ширхэг нүд

6x6 талбайд нэг давхаргад 12 боломжит мөр байна, мөр бүр 6 нүдтэй.

Мөр арилсны дараа дээр нь өлгөөтэй үлдсэн шоонууд **доош унана**
(багана тус бүрээр шахагдана). Унасан шоонууд шинэ мөр үүсгэвэл
дахин цэвэрлэгдэж, **гинжин урвал** үүснэ. Гинж үргэлжлэх тусам
онооны үржүүлэгч x1, x2, x3 гэж өснө.

Таталцал зөвхөн цэвэрлэгээний дараа ажиллана. Цэвэрлэгээгүй үед дүрс
нүхэн дээр тогтож болно — энэ нь хэвийн.

## Оноо

| Эх үүсвэр | Оноо |
|---|---|
| Устгасан шоо бүр | `12 × гинжийн дугаар` |
| Цэвэрлэсэн мөр бүр | `30 × гинжийн дугаар` |
| Шидэхэд (hard drop) унасан нүд бүр | `2` |

`scripts/game.gd`-ийн эхэнд `POINTS_PER_BLOCK`, `ROW_BONUS`,
`HARD_DROP_POINTS` гэсэн тогтмолуудаас өөрчилж болно.

## Дээд амжилт

`ConfigFile` ашиглан `user://tetris3d.cfg` файлд автоматаар хадгалагдана.
Оноо дээд амжилтыг давсан даруйд, тоглоом дуусахад, мөн цонх хаагдахад
хадгална.

Файлын бодит байрлалыг Godot дотроос **Project → Open User Data Folder**
цэсээр нээж харж болно. Дээд амжилтыг тэглэхийн тулд тэр файлыг устгана.

## Файлын бүтэц

```
project.godot        — төслийн тохиргоо
main.tscn            — үндсэн scene (камер, гэрэл, орчин)
scripts/
  pieces.gd          — дүрснүүдийн тодорхойлолт + эргэлтийн математик
  board.gd           — талбайн ӨГӨГДӨЛ ба ЛОГИК (график огт байхгүй)
  game.gd            — зурах, оролт, цаг тоолох
```

## Архитектурын гол зарчим

**Логик ба графикийг тусгаарлах.**

`board.gd` бол зөвхөн тоонуудтай ажилладаг цэвэр өгөгдлийн класс. Түүнд
Godot-ын Node, Mesh, Camera гэх зүйл огт хамаагүй. Хэрэв `board.gd` зөв
ажиллаж байвал тоглоом чинь бэлэн болсон гэсэн үг.

`game.gd` бол зөвхөн "орчуулагч": Board дотор `-1` биш утга байвал тэр
байрлалд шоо зурна. Оролтыг Board руу дамжуулна. Таймер тоолно.

Энэ тусгаарлалтын ачаар:
- Логикоо дэлгэцгүйгээр туршиж болно
- Графикаа бүхэлд нь сольсон ч логик нь хөдлөхгүй
- Алдаа гарвал аль талд нь байгаа нь шууд мэдэгдэнэ

## Харагдах байдал

Камер **нэг л байрлалд тогтсон** — эргүүлэх товчлуур байхгүй. Өнцгийг нь
кубын булан руу харахаар тавьсан:

```
yaw   = 45°
pitch = atan(1 / √2) ≈ 35.264°
```

Эдгээр нь камерыг кубын их диагональ буюу `(1,1,1)` вектор дээр байрлуулна.
Тэр цэгээс кубын гурван тал яг тэнцүү хэмжээтэй харагдана — жинхэнэ изометр.

Үүний хариуд торны тэнхлэгүүд дэлгэц дээр налуу (хэвтээгээс 30°) харагдана.
Тиймээс сумны товчлуурууд налуу ажиллана:

| Товч | Дэлгэц дээр |
|---|---|
| `↑` | ↗ дээш-баруун |
| `→` | ↘ доош-баруун |
| `↓` | ↙ доош-зүүн |
| `←` | ↖ дээш-зүүн |

Дөрвүүлээ тогтвортой эргэсэн тул хэдэн минутын дараа дасна. Хэрэв таагүй
бол `CAM_YAW_DEG`-ийг 0 болгоход сумнууд шууд дэлгэцийн дагуу явна
(гэхдээ худгийн зөвхөн нэг тал харагдана).

Дүрс хаана буухыг харуулах тунгалаг сүүдэр (`SHOW_GHOST`) асаалттай.
Гэрлийн тусгах хар сүүдэр (`CAST_SHADOWS`) унтраалттай.

Камерын зай нь талбайн хэмжээнээс **автоматаар** бодогддог: худгийн орой
(дүрс төрдөг газар) яг багтах зайг `fov`-оос тооцно. Тиймээс `H`-ийг
өөрчлөхөд камер өөрөө дагаж тохирно.

`zoom = 1.0` нь "бүтэн худаг багтсан" байрлал. Үүнээс доош (ойртуулж)
томруулахад худгийн орой дэлгэцнээс тасарч эхэлнэ — овоолго намхан
байхад энэ нь хэвийн, гэхдээ дүрс төрөхийг харахад `0` дарж сэргээ.

Сонгосон томруулалт болон удирдлагын жагсаалт харагдах эсэх нь
`user://tetris3d.cfg`-д хадгалагдана.

| Тогтмол | Утга | Тайлбар |
|---|---|---|
| `CAM_PITCH_DEG` | 35.264 | Камер хэвтээгээс хэдэн градус дээр байх вэ |
| `CAM_YAW_DEG` | 45 | Камер хэвтээ хавтгайд хэдэн градус эргэсэн бэ |
| `SHOW_GHOST` | true | Буух байрлалыг урьдчилан харуулах эсэх |
| `CAST_SHADOWS` | false | Шоо сүүдэр тусгах эсэх |
| `CUBE_SIZE` | 0.94 | Шооны хэмжээ (нүд нь 1.0). 1.0 болговол зай алга болно |
| `GHOST_SCALE` | 0.90 | Сүүдрийн шоо жижиг байх харьцаа |
| `ZOOM_MIN` / `ZOOM_MAX` | 0.65 / 2.0 | Томруулалтын хязгаар |

## Тохируулж болох зүйлс

`scripts/game.gd` дотор:

| Хувьсагч | Утга | Тайлбар |
|---|---|---|
| `W`, `D`, `H` | 6, 6, 12 | Талбайн хэмжээ. `W` ба `D` нь мөр дүүргэхэд шаардлагатай нүдний тоо |
| `FALL_INTERVAL` | 1.0 | Унах хурд (секунд) — тоглоомын турш тогтмол |

| `DAS_DELAY` / `DAS_RATE` | 0.17 / 0.06 | Товч дарж барихад давтан хөдлөх хугацаа |
| `POINTS_PER_BLOCK` | 12 | Устгасан шоо тутамд өгөх оноо |
| `ROW_BONUS` | 30 | Цэвэрлэсэн мөр тутамд нэмэлт оноо |
| `KICKS` | | Эргэлт хананд мөргөх үед оролдох түлхэлтүүд |

## Дүрснүүд

Долоон сонгодог тетромино, стандарт өнгөтэйгөө:

| Дүрс | Өнгө | Хэлбэр |
|---|---|---|
| I | цайвар цэнхэр | шулуун дөрөв |
| J | хөх | зүүн дээд өнцөгт цухуйсан |
| L | улбар шар | баруун дээд өнцөгт цухуйсан |
| O | шар | 2x2 дөрвөлжин |
| S | ногоон | дээд хос баруун тийш шилжсэн |
| T | ягаан | дунд нь цухуйсан |
| Z | улаан | дээд хос зүүн тийш шилжсэн |

**Одоогоор зөвхөн I, J, L, O, T тавыг ашиглаж байна.** S ба Z хоёрыг хассан:
эдгээр нь аль ч талаар нь тавихад доороо нүх үлдээдэг цорын ганц дүрс бөгөөд
нэг нүх ч мөр дүүргэхэд ноцтой саад болдог.

Анхааруулга: талбай 6x6 болсон тул мөр дүүргэхэд 5 биш **6 нүд** хэрэгтэй.
Санамсаргүй тоглолтын хэмжилтээр 5x5 үед 60–100 мөр цэвэрлэгддэг байсан бол
6x6 дээр 23–36 болж буурсан. Хэцүү санагдвал `ACTIVE`-ийг `[2, 3, 5]`
(L, O, T) болгож богиносгох, эсвэл `W`, `D`-г буцаан 5 болгоно уу. `pieces.gd` доторх
`ACTIVE` жагсаалтаас буцааж нэмэх, эсвэл цааш багасгах боломжтой.

Бүгд хавтгайд хэвтэж эхэлдэг ч `Z`/`C` товчоор хөмрүүлэхэд босоо байрлалд
орно — 3D-д тэдгээр нь хавтгай дүрс байхаа больж, гүн рүү сунана.

Анхаарах нэг зүйл: 2D-д тольдсон хос болох **J/L** ба **S/Z** нь 3D-д
эргэлтээр бие биендээ хувирдаг. Тиймээс геометрийн хувьд ердөө 5 ялгаатай
дүрс байгаа боловч өнгө нь өөр учраас тоглоход ялгаатай мэдрэгдэнэ.

`scripts/pieces.gd` дотор `SHAPES` массивд шинэ дүрс нэмж болно —
`Vector3i` offset-уудын жагсаалт бичээд, `NAMES` ба `COLORS`-д
харгалзах утга нэмэхэд л хангалттай. Дүрс 4 шооноос өөр тооны шоотой
байж болно, код нь ерөнхий бичигдсэн.
