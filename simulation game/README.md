# Хонь туугч — Godot 4 прототип

Сүргийн симуляци тоглоом. **Та хоньчны нохой.** Хонь бүр зөвхөн ойрхон хөршүүдээ
харж 5 энгийн дүрмээр хөдөлнө. «Сүрэг» гэж кодонд хаана ч бичээгүй ч хонинууд
бөөгнөрч, хамт гүйж, нохой, чоноос зугтаж, сандрал нь давалгаа шиг тархдаг.
Энэ бол **симуляци**: дүрмийг нь бичнэ, үр дүн нь өөрөө үүснэ.

## Түвшнүүд
Түвшин бүр симуляцид нэг шинэ хүчин зүйл нэмнэ. Өмнөх түвшинг давбал дараагийнх нээгдэнэ
(од `user://progress.cfg`-д хадгалагдана).

| # | Нэр | Шинэ зүйл | Хонь / Зорилго / Цаг |
|---|---|---|---|
| 1 | Бэлчээр | Суурь: сүргийг ардаас шахаж сурах | 12 / 10 / 60 с |
| 2 | Бут | Саад: сүрэг хуваагдаж, буцаж нийлнэ | 16 / 14 / 60 с |
| 3 | Чоно | Махчин: хамгийн ойр хонийг агнана, нохойноос айна | 16 / 12 / 75 с |
| 4 | Гол | Хонь усанд ордоггүй, зөвхөн гүүрээр гарна. Чоно сэлдэг | 18 / 14 / 80 с |
| 5 | Шуурга | 8–12 сек тутам салхи сүргийг тараана, хоёр чоно | 20 / 15 / 90 с |

- **Од:** цагийн 40%-иас их үлдвэл ★★★, 20%-иас их бол ★★, бусад нь ★
- **Ялагдах:** цаг дуусах, эсвэл чоно хэт олон хонь идэж зорилгод хүрэх боломжгүй болох
- Нэг хар хонь **зөрүүд**: сүргээ бага дагаж, нохойноос бага айдаг
- Тоглолтын дундуур дүрэм өөрчилбөл **туршилтын горим** болж, од хадгалагдахгүй

## Удирдлага
| Товч | Үйлдэл |
|---|---|
| Хулгана | Нохой хулганыг дагана |
| Зүүн товч / Space | Эхлэх. Тоглож байхад хуцна (2 сек тутамд): хонь сандарч, чоно зугтана |
| ← / → | Цэс дээр түвшин сонгох |
| 1–5 | Ойртох / Дагах / Зай барих / Айх / Сандрал халдах дүрмийг асаах, унтраах |
| D | Хүчний сум, айх тойрог, чонын бай харах |
| T | Хонь бүрийн сүүлийн 4 секундын мөр |
| Tab | Симуляцийн самбар нуух, харуулах |
| R | Түвшинг шинээр эхлүүлэх |
| Esc | Цэс рүү буцах |

## Симуляцийн дүрмүүд
**Хонь** (`scripts/sheep.gd`) — зөвхөн 45 px дотор байгаа хөршүүдээ хардаг:

| Дүрэм | Юу хийдэг | Сумны өнгө |
|---|---|---|
| 1. Ойртох | Хөршүүдийнхээ төв рүү явна | ногоон |
| 2. Дагах | Хөршүүдийнхээ дундаж чиглэлд эргэнэ | цэнхэр |
| 3. Зай барих | 13 px-ээс ойр хоньноос холдоно | шар |
| 4. Айх | Нохой (85 px), чоно (100 px) ойртвол зугтана | улаан |
| 5. Сандрал халдах | Ойрхон айсан хөршийн айдсын 80% шилжинэ | — (хонь улайна) |

Сандарсан хонь илүү хурдан гүйж, сүргээ илүү хүчтэй дагадаг. Айдас аажмаар буурна.

**Чоно** (`scripts/wolf.gd`) — гурван төлөвтэй: тэнэх → хашаанаас гадуурх хамгийн ойр
хонийг агнах → нохой 70 px-ээс ойртох эсвэл хуцвал 2.5 сек зугтах. Хонь барьвал 5 сек цадна.

**Самбар** (баруун дээд): дундаж айдас, хэдэн тусдаа бүлэгт хуваагдсан (30 px-ээс ойр
хонинууд нэг бүлэг), төвөөс дундаж зай. График: улаан = айдас, цагаан = бүлгийн тоо, сүүлийн 10 секунд.

## Дуу
`scripts/sounds.gd` симуляцид нөлөөлөхгүй, зөвхөн сонсдог. Бичлэгүүд `sounds/` хавтсанд, эх сурвалж нь `sounds/CREDITS.md`-д бий.

| Амьтан, орчин | Хэзээ сонсогдох вэ |
|---|---|
| Хонь | Тайван үед хааяа майлна, хашаанд ороход майлна. Сандрахад 1.2 сек тутам нэг хонь чангаар майлна. Нэг дор хамгийн ихдээ 2 хонь дуугарна |
| Нохой | Хуцахад, чоно 110 px-ээс ойртоход архирна |
| Чоно | Гарч ирэхэд, 20–35 сек тутам улина. Агнаж эхлэхэд архирч, зугтахдаа яйлна |
| Сүрэг | Хурдлах тусам туурайн чимээ чангарна |
| Салхи, гол | Сэвшээ салхи үргэлж, шуурга үлээхэд чангарна. Голтой түвшинд ус урсана |

Хонь бүр өөр дуутай, зөрүүд хар хонь бүдүүн дуутай. Дуу амьтны байрлалаас хамаарч зүүн, баруун чихэнд сонсогдоно. Цэс, үр дүнгийн үед бүх дуу намсна.

## Нээх
1. Godot 4.7 нээгээд **Import** → энэ хавтасны `project.godot` файлыг сонго.
2. **F5** (Run Project) дар.

## Файлын бүтэц
| Файл | Юу хийдэг |
|---|---|
| `scripts/main.gd` | Түвшин ачаалах, төлөв (MENU/PLAY/OVER), цаг, хуцалт, чоно, салхи, хэмжилт, ахиц хадгалах, цэсний автомат нохой |
| `scripts/levels.gd` | 5 түвшний тохиргоо: хонь, зорилго, цаг, бут, ус, чоно, салхи |
| `scripts/agent.gd` | Хонь, чонын суурь: хурд, радиус |
| `scripts/sheep.gd` | Нэг хонь: 5 дүрэм, айдас, мөр, зурах |
| `scripts/wolf.gd` | Чоно: тэнэх, агнах, зугтах |
| `scripts/dog.gd` | Нохой: хулгана дагах, хуцах, хүлээх хугацаа |
| `scripts/field.gd` | Бэлчээр, хашаа, бут, гол, гүүр, мөргөлдөөн |
| `scripts/trails.gd` | T товчны мөр |
| `scripts/effects.gd` | «+1» бичиг, ноосны үүл, салхины зураас |
| `scripts/hud.gd` | Дээд мөр, доод хоосон мөр, самбар, түр бичиг, цэс, үр дүн, од |
| `scripts/sounds.gd` | Амьтдын дуу, туурай, салхи, гол |
| `sounds/` | Дууны файлууд, `CREDITS.md` |
